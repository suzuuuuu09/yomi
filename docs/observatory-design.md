# Observatoryの実装仕様

承認されたAmbient Cosmosの最終デザインボードを基準に、既存の書籍管理機能を維持する。

- Noto Sans JPを使用し、濃紺の空間に星・青紫の宇宙塵・星雲を3D配置する。星雲は以前の生成画像の色と濃淡を使い、厚みのある雲として描画する。カメラに追従させず、視点移動で雲の重なりや星との位置関係が変わる。
- 本の星は四芒星と発光で装飾用の微小な星から区別する。進捗に応じて明るさ・大きさが変化し、選択時は輪で強調する。
- PCのヘッダーはYOMi、検索、本の一覧、設定。検索と状態フィルターは展開して使う。
- 0冊時は、読み込み完了後に見出し「あなたの宇宙は、ここから始まる。」、説明「最初の本を登録して、自分だけの星空を作ろう。」、登録ボタン「最初の星を生み出す」を表示する。検索・一覧・統計・読書中ショートカットは表示しない。
- 本の詳細はPCで右側、モバイルで下半分以内のボトムシート。書影、書名、著者、状態、ページ数、進捗バーを表示する。
- 「読書を記録する」が主操作。展開した入力・加減算から既存の進捗APIで保存する。メモと編集は副操作。統計・ログ訂正・書籍情報・アーカイブも詳細から開ける。
- 読書中の本への入口は左下のコンパクトなショートカット。本の追加は右下。モバイルでは詳細シートの上に本の追加操作を配置する。
- 書名ラベルは画面内に投影し、選択・ホバーした本を優先する。ズームや視点に応じて画面外・重複・パネルに隠れるラベルを非表示にする。PC最大7件、モバイル最大3件を目安とする。
- 星以外に本の一覧からも選択・編集できる。動きを減らすOS設定では星・宇宙塵・星雲・星座線の動きを止める。

認証・HTTP API・保存データの形式は変更しない。画像に描かれた固定の書籍や星座はサンプルであり、アプリでは実際の蔵書・座標・読了した本同士の既存の星座条件を使う。

## 画像素材

`public/textures/ambient-dust.png` と `public/textures/book-star.png` は、承認されたデザインボードを参照して生成した素材。星雲は元画像を雲の色・濃淡の元にし、奥行きごとに参照位置と密度を変えるボリューム描画で再現する。球を引き伸ばした2つの領域内を32点ずつサンプリングし、カメラが雲の中に入っても描画する。本のスプライト、宇宙塵、星座線、視点操作もThree.jsで描画する。書影は引き続き各書籍の保存済みURLを使う。
