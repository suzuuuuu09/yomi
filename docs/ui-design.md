# UI/UX

## デザイン原則

- 3Dの星空を背景に置き、操作パネルを重ねる。
- 登録時の星の誕生、読書中のまたたき、読了した本同士の星座線で状態を表す。
- 半透明のパネルを使い、星空を見ながら検索・記録できる構成にする。

## 画面構成

- `/`: 紹介ページ。
- `/login`: Googleログイン画面。認証後は `/app` へ遷移する。
- `/app`: 星空と読書管理画面。Cookieの有無をNext.jsミドルウェアで確認し、`SessionGuard` が実セッションを検証する。

`src/app/(app)/layout.tsx` はフォント・共通スタイル・メタデータを設定する。
星空と操作パネルは `src/app/(app)/app/page.tsx` で組み立てる。`UniverseCanvas` はクライアントで動的に読み込み、画面全体に固定表示する。星・星座線・星雲は同じR3F Canvas内に描画する。

## Observatory（メイン画面）

- 上部: 登録済みの本をタイトル・著者・ジャンルの部分一致で検索する。状態タブは「すべて」「読書中」「未読」「読了」で、各件数を表示する。本の一覧とユーザーメニューを開くボタンも置く。
- 星空: ドラッグなどで視点を操作し、星のクリック・タップで本の詳細を開く。
- 右下: 本を追加するボタン。
- 下部ドック: 読書中の本を最大3冊表示し、進捗バー・ページ数・`+1P` ボタンを置く。読書中の本がなければ非表示。配置はPanda CSSの `HStack` を使う。
- 統計: PC向けの表示で、アーカイブされていない本の数、読了した本の数（表示名は `constellations`）、連続読書日数を表示する。
- タッチ端末: ジャイロで視点を操作する「VRモード」の切り替えを表示する。センサーの許可・対応状況に依存する。許可が得られるまでジャイロ操作を有効にせず、拒否・エラー時もモードを終了できる。
- 初回: 操作説明を表示し、完了状態をブラウザのlocalStorageに保存する。

実装: `TopBar`、`UniverseCanvas`、`BottomDock`、`StatsOverlay`、`TutorialOverlay`。

## 本の追加

中央のモーダルで「キーワード」「ISBN」「手動入力」を切り替える。検索はGoogle Books APIを使い、候補の書影・書誌情報を表示する。ISBNモードではカメラによるバーコード読み取りも使える。

タイトル・著者・ページ数・ISBN・ジャンルを登録する。検索候補の選択時に3Dの星のプレビューは表示しない。保存が成功してから星空に追加し、誕生エフェクトを表示する。保存中は入力・モード切替・閉じる操作を無効にし、保存失敗時は入力内容を残す。

実装: `AddBookModal`、`useAddBook`、`useBookSearchStore`、`BarCodeScanner`。

## Star Insight（本の詳細）

選択した本を右側のパネルに表示する。

- 書影、タイトル、著者、状態、登録日・読了日などの情報。
- 読書進捗とページ数の加算・直接入力、書誌情報の編集。編集画面は開くたびに保存済みの値から始める。
- Reading Graph: 選択した本に限定せず、アーカイブ済みを含む全冊の過去14日間の読書量と読書タイムゾーンを表示する。
- 読書ログ: 選択した本の日別記録を訂正・削除する。ログの訂正は現在ページに反映しない。
- 読書メモ: ページ番号を任意で付けて追加・削除する。0ページは紐付けられない。保存成功時にだけ下書きを消す。
- アーカイブと完全削除: 確認画面を表示する。アーカイブは履歴を保持し、完全削除は関連ノート・ログも削除する。

複数タグを付ける「Nebula Tags」は未実装。現在の関連付けは本ごとの単一の `genre` を使う。

実装: `StarInsightPanel`、`BookEditModal`、`DelBookModal`、`useStarInsight`。

## 本の一覧・ユーザー設定

`BookListDrawer` は登録済みの本を検索・状態で絞り込み、選択した本の詳細を開く。
`UserMenu` からログアウト、読書タイムゾーンの保存、アーカイブ済み書籍の確認・復元ができる。
