# UI/UX

## デザイン原則

- 3Dの星空を蔵書の操作面とし、濃紺の空間に星・青紫の宇宙塵・柔らかな星雲を配置する。星雲は元の生成画像の色と濃淡を使ったボリューム描画とし、視点移動による遠近差を保つ。
- 登録時の星の誕生、読書中のまたたき、読了した本同士の星座線で状態を表す。
- 読みやすい濃紺のガラス調パネルとNoto Sans JPを使う。最終デザインの仕様は [observatory-design.md](./observatory-design.md) に記録する。

## 画面構成

- `/`: 紹介ページ。
- `/login`: Googleログイン画面。認証後は `/app` へ遷移する。
- `/app`: 星空と読書管理画面。Cookieの有無をvinextのNext.js互換の `src/proxy.ts` で確認し、`SessionGuard` が実セッションを検証する。

`src/app/(app)/layout.tsx` はフォント・共通スタイル・メタデータを設定する。
星空と操作パネルは `src/app/(app)/app/page.tsx` で組み立てる。`UniverseCanvas` はクライアントで動的に読み込み、画面全体に固定表示する。星・星座線・宇宙塵・星雲は同じR3F Canvas内に描画する。

## Observatory（メイン画面）

- 上部: YOMiのワードマークと「検索」「本の一覧」「設定」。検索を開くとタイトル・著者・ジャンルの部分一致検索と状態フィルターを表示する。
- 0冊: 読み込み後にEmpty Stateと「最初の星を生み出す」を表示する。検索・一覧・統計・読書中ショートカットは非表示。
- 星空: ドラッグ・ズームで視点を操作し、星または書名ラベルのクリック・タップで本の詳細を開く。ラベルの重なりは画面上の位置と選択状態で抑制する。
- 右下: 本を追加するボタン。モバイルでは詳細シートの上に移動する。
- 左下: 読書中の一冊へのコンパクトなショートカット。モバイルでは詳細を開いている間は非表示。
- タッチ端末: タッチ操作で視点を移動する。
- 初回: Empty Stateが最初の登録を案内する。全面を覆うチュートリアルは表示しない。

実装: `TopBar`、`UniverseCanvas`、`BottomDock`、`ObservatoryEmptyState`。

## 本の追加

中央のモーダルで「キーワード」「ISBN」「手動入力」を切り替える。検索はGoogle Books APIを使い、候補の書影・書誌情報を表示する。ISBNモードではカメラによるバーコード読み取りも使える。

タイトル・著者・ページ数・ISBN・ジャンルを登録する。検索候補の選択時に3Dの星のプレビューは表示しない。保存が成功してから星空に追加し、誕生エフェクトを表示する。保存中は入力・モード切替・閉じる操作を無効にし、保存失敗時は入力内容を残す。

実装: `AddBookModal`、`useAddBook`、`useBookSearchStore`、`BarCodeScanner`。

## Star Insight（本の詳細）

選択した本をPCでは右側のコンパクトなパネル、モバイルでは下半分以内のボトムシートに表示する。

- 書影、タイトル、著者、状態、登録日・読了日などの情報。
- 「読書を記録する」からページ数の加減算・直接入力を展開する。「メモ」「編集」は副操作とし、統計・ログ・書籍情報・アーカイブは詳細から展開する。編集画面は開くたびに保存済みの値から始める。
- Reading Graph: 選択した本に限定せず、アーカイブ済みを含む全冊の過去14日間の読書量と読書タイムゾーンを表示する。
- 読書ログ: 選択した本の日別記録を訂正・削除する。ログの訂正は現在ページに反映しない。
- 読書メモ: ページ番号を任意で付けて追加・削除する。0ページは紐付けられない。保存成功時にだけ下書きを消す。
- アーカイブと完全削除: 確認画面を表示する。アーカイブは履歴を保持し、完全削除は関連ノート・ログも削除する。

複数タグを付ける「Nebula Tags」は未実装。現在の関連付けは本ごとの単一の `genre` を使う。

実装: `StarInsightPanel`、`BookEditModal`、`DelBookModal`、`useStarInsight`。

## 本の一覧・ユーザー設定

`BookListDrawer` は登録済みの本を検索・状態で絞り込み、選択した本の詳細を開く。
`UserMenu` からログアウト、読書タイムゾーンの保存、アーカイブ済み書籍の確認・復元ができる。
