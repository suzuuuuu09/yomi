# ゲストとアカウントの記録を独立させる

ログイン不要で使い始められるよう、ゲストの蔵書・読書記録はブラウザー内に保存する。ログインしただけでは転送せず、利用者が選んだ場合にアカウントへ引き継ぐ。同じISBNでも再読など別の記録である可能性があるため、自動統合・上書きはせず別の本として追加し、同じ引き継ぎの再試行による二重登録は防ぐ。

引き継ぎ後も元のゲストデータを端末に残し、以降は同期しない。自動的に管理先を一本化する方式より、元の記録を失わず確認できることを優先する。画面では現在の保存先と同期されないことを明示する。

ゲストのバックアップはファイルへ書き出し、復元時は確認とファイル全体の検証を経てゲストデータだけを置き換える。アカウントの記録には影響させない。
